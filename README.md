# Craft Ora - Hamper Catalog App

This is a beautiful, cross-platform Flutter application built for the "Craft Ora" small business. It showcases the "05 Mini Hamper" collection and optional add-ons in an elegant, pink-themed, responsive interface.

## Features
- **Responsive Layout**: Adapts gracefully to mobile, tablet, and desktop screens.
- **Hamper Packages**: Displays the ₹99, ₹149, ₹199, and ₹249 hamper tiers with their included items.
- **Extra Charges Section**: Clearly lists available add-ons like fairy lights, polaroids, and custom letters.
- **Modern UI**: Uses Material 3 with a beautiful `deep pink` color scheme.

## Tech Stack
- Flutter
- Dart
- Material 3 Design

## Setup & Run
1. Ensure you have Flutter installed.
2. Clone this repository.
3. Run `flutter pub get` to install dependencies.
4. Run `flutter run` to launch the app on your preferred device or emulator.
